01 — SYSTEM OVERVIEW

시스템 개요

SENSOR → PLC → ACTUATOR
INPUT

감지

포토 센서와 리밋 스위치가 물체의 위치와 통과 여부를 감지해 PLC로 신호를 전달합니다.

LOGIC

PLC 제어

래더 다이어그램으로 작성된 로직이 입력 신호를 판단해 모터 구동 조건을 결정합니다.

OUTPUT

구동

모터와 릴레이가 구동되어 컨베이어 벨트를 이동시키고, 경광등으로 상태를 표시합니다.

FEEDBACK

검증

3D 모델링으로 실제 프레임·롤러 배치를 시뮬레이션해 설계 오차를 사전에 점검합니다.
